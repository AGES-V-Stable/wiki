# Painel Cliente PME

## Conta

### US001 — Cadastrar conta PME

*Como Cliente PME,
Quero cadastrar a conta da minha empresa,
Para utilizar a plataforma de pagamentos internacionais.*

### US002 — Verificar situação cadastral da conta PME

*Como Cliente PME,
Quero verificar a situação cadastral da minha conta,
Para saber a situação do cadastro da minha empresa.*

### US003 — Entrar em conta PME

*Como Cliente PME,
Quero entrar na minha conta,
Para acessar as funcionalidades da plataforma.*

### US004 — Gerenciar conta PME

*Como Cliente PME,
Quero gerenciar a conta da minha empresa,
Para manter seus dados atualizados.*

### US005 — Adicionar saldo

*Como Cliente PME,
Quero adicionar saldo à minha conta,
Para ter recursos disponíveis para realizar transferências internacionais.*

## Transferências

### US006 — Realizar transferência

*Como Cliente PME,
Quero realizar uma transferência internacional,
Para efetuar uma operação de pagamento internacional.*

### US007 — Visualizar detalhes da transferência

*Como Cliente PME,
Quero visualizar os detalhes de uma transferência,
Para consultar as informações da operação realizada.*

### US008 — Visualizar histórico de transferências

*Como Cliente PME,
Quero visualizar o histórico de transferências,
Para acompanhar as operações realizadas pela minha empresa.*

## Beneficiários

### US009 — Cadastrar beneficiário

*Como Cliente PME,
Quero cadastrar um beneficiário,
Para utilizá-lo nas minhas transferências internacionais.*

### US010 — Visualizar beneficiários

*Como Cliente PME,
Quero visualizar os beneficiários cadastrados,
Para consultar as contrapartes disponíveis para minhas transferências.*

### US011 — Gerenciar beneficiários

*Como Cliente PME,
Quero gerenciar os beneficiários cadastrados,
Para manter seus dados atualizados.*

## Dashboard

### US012 — Visualizar saldo disponível

*Como Cliente PME,
Quero visualizar o saldo disponível da minha conta,
Para saber os recursos disponíveis para utilização.*

### US013 — Visualizar economia acumulada

*Como Cliente PME,
Quero visualizar a economia acumulada,
Para acompanhar os benefícios obtidos com a utilização da plataforma.*

### US014 — Visualizar volume transacionado

*Como Cliente PME,
Quero visualizar o volume transacionado,
Para acompanhar o total das operações realizadas pela minha empresa.*

### US015 — Visualizar câmbio atual

*Como Cliente PME,
Quero visualizar o câmbio atual,
Para consultar a taxa de câmbio utilizada nas operações.*

### US016 — Visualizar histórico do volume de remessas

*Como Cliente PME,
Quero visualizar o histórico do volume de remessas,
Para acompanhar a evolução das operações realizadas pela minha empresa.*

### US017 — Visualizar histórico de economia

*Como Cliente PME,
Quero visualizar o histórico de economia,
Para acompanhar a evolução da economia obtida com as operações realizadas.*

### US018 — Visualizar últimas transferências

*Como Cliente PME,
Quero visualizar as últimas transferências,
Para acompanhar as operações mais recentes da minha empresa.*

### US019 — Filtrar dados

*Como Cliente PME,
Quero filtrar os dados apresentados na plataforma,
Para encontrar as informações relevantes para minha consulta.*

## Nice to Have

### US020 — Cadastrar operadores

*Como Cliente PME,

### US021 — Visualizar operadores

*Como Cliente PME,
Quero visualizar os operadores cadastrados,

### US022 — Gerenciar operadores

*Como Cliente PME,
Quero gerenciar os operadores cadastrados,

### US023 — Gerar relatórios de auditoria

*Como Cliente PME,
Quero gerar relatórios de auditoria,
Para consultar e acompanhar as atividades realizadas na conta da empresa.*
